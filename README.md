# にほん電脳横丁アイコンコンテスト 投票ページ（artwork-vote）

15作品から1作品を選ぶ本投票と、上位作品による決選投票を行うページです。
構成：GitHub Pages（`index.html`）＋ GAS ＋ スプレッドシート

```
artwork-vote/
├── index.html   … 投票ページ
├── ogp.png      … リンクプレビュー用画像（ご自身で用意・1200×630px推奨・5MB以下）
├── images/      … 作品画像（英数字のファイル名に改名して配置）
│   ├── 01.png
│   └── …
├── Code.gs      … GAS（リポジトリには置かなくてもOK）
└── README.md
```

---

## セットアップ手順

### 1. スプレッドシートとGAS

1. Googleスプレッドシートを新規作成する
2. 「拡張機能 → Apps Script」を開き、`Code.gs` の中身をすべて貼り付けて保存
3. 関数 `setupSheets` を選んで「実行」（初回は権限の承認が必要）
   → `works` / `config` / `votes_main` / `votes_final` / `tally` の5シートが作られます

### 2. 作品リストを入力（`works` シート）

| No | タイトル | 画像ファイル名 |
|---|---|---|
| 1 | 作品タイトル | 01.png |
| 2 | 作品タイトル | 02.png |

- No は 1, 2, 3… の数字
- 画像ファイル名は `images/` に置いたファイル名と**大文字小文字まで完全一致**させる（例：`01.PNG` と `01.png` は別物）

### 3. GASをウェブアプリとしてデプロイ

1. Apps Script 右上「デプロイ → 新しいデプロイ」
2. 種類：ウェブアプリ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. デプロイ後、関数 `makeEncodedUrl` を実行
4. 実行ログに出る `ENC_API : xxxxx` の xxxxx をコピー

### 4. index.html に設定

`index.html` の次の行に、コピーした値を貼り付けます。

```js
var ENC_API = '';   // ← ここに貼る
```

### 5. GitHub に公開

1. リポジトリ `artwork-vote` を作成
2. `index.html`、`ogp.png`、`images/` フォルダをアップロード
3. Settings → Pages → Branch を `main` / `(root)` にして保存
4. 数分後 `https://kintsuba1992.github.io/artwork-vote/` で公開されます

## 運用（フェーズ切替）

`config` シートの B2 セルをプルダウンで切り替えるだけです。

| 値 | 状態 |
|---|---|
| `closed` | 受付終了（初期値） |
| `main` | 本投票（全作品を表示） |
| `final` | 決選投票（`tally` の決選フラグ TRUE の作品のみ表示） |

### 決選投票への切替手順

1. `config` を `closed` にして本投票を締め切る
2. `tally` シートの J4「状態」を確認
   - `OK` … 決選候補はちょうど3作品
   - `⚠ 同票のため決選候補がN作品です` … 3位が同票。同票作品はすべて決選に進みます
3. `config` を `final` にする → 決選投票開始
4. 終了したら `closed` に戻す。決選の結果は `tally` の F列・G列で確認

### 補足

- 得票数はページにもGASの応答にも出ません。`tally` シートでのみ確認できます
- 作品の表示順はページを開くたびにランダムになります（並び順による有利不利を防ぐため）。No は作品固有の番号で、表示位置とは関係ありません
- 同じTelegramIDは各フェーズで1回のみ（本投票と決選はそれぞれ1回ずつ投票可能）
- IDは `@` 除去・小文字化して記録します（`@Abc` と `abc` は同一扱い）
- 投票した端末には記録が残り、同じ端末からの再投票画面は表示されません（簡易的な抑止。シークレットモードや別端末では防げません）
- `setupSheets` を再実行すると `tally` シートは作り直されます（投票記録・作品リストは消えません）
- **作品リストの行を途中で削除・並べ替えしないでください**（tally の集計がずれます）

## Telegram リンクプレビュー（OGP）

- `ogp.png` をリポジトリ直下に置く（ファイル名は小文字で `ogp.png`）
- プレビュー文言
  - タイトル：にほん電脳横丁アイコンコンテスト投票受付中！
  - 説明：作品の中からお気に入りの1作品に投票してください。
- 本投票・決選とも同じプレビューです。受付終了後も「受付中！」のまま表示されるため、終了後はURLを共有しないでください

### プレビューが出ない・古いままのとき

Telegram はプレビューをキャッシュします。Telegram で `@WebpageBot` を開き、ページのURLを送信すると最新の内容に更新されます。
